# アニマル・スプラッシュ・スライダー

デフォルメされた動物たちがウォータースライダーを滑り降り、地上のプールへ一番乗りで着水することを目指す 3D (WebGL / three.js) レースゲームです。Android・iPhone・iPad のブラウザ向け PWA です。

## ルール
- コンピュータ 3 体と対戦。プールに最初に着水すればクリア → 次のステージへ。
- スライダーからはみ出して自由落下できます。下のスライダーに着地すればショートカット、プールに直接飛び込んでも OK。
- プール以外の地面に落ちると爆散して失敗。
- 勝ち続けている間は次のステージが自動でスタートします（結果画面の「オート停止」で止められます）。

## 操作
- ◀ ▶ : 左右移動（空中でも少し曲がれる） / JUMP : ジャンプ（◀▶ と同時押しで横に飛び出す）
- PC: ← → / A D、スペース

## 開発
```sh
npm install
npm run dev        # 開発サーバ
npm test           # ユニットテスト (vitest)
npm run test:e2e   # E2E テスト (Playwright: Pixel 7 / iPhone 14 / iPad Pro 11 エミュレーション)
npm run build      # dist/ に出力
npm run icons      # PWA アイコン再生成
```

## 公開
`main` ブランチに push すると GitHub Actions (`.github/workflows/deploy.yml`) がテスト → ビルド → GitHub Pages へデプロイします。

## アップデート
Service Worker (vite-plugin-pwa) が起動時・60 秒ごと・画面復帰時に更新を確認します。新バージョンはレース中には適用されず、結果画面やタイトル画面に戻ったタイミングで適用されます。連勝中の場合は更新後もそのまま次のステージから再開します。
